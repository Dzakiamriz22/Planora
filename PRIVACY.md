# Kebijakan Privasi Planora

Planora dibuat agar data keuangan pribadi kamu tetap menjadi milik kamu sepenuhnya.

- **Semua data disimpan lokal di HP:** Profil, penghasilan, biaya hidup, tujuan tabungan, rincian instrumen, catatan setoran, transaksi saham, Plan, catatan arus kas (pemasukan dan pengeluaran), catatan harga, dan foto profil hanya tersimpan di penyimpanan internal HP kamu.
- **Tanpa akun & tanpa internet:** Planora tidak meminta pendaftaran/login, tidak memakai izin internet, dan tidak mengirim data apa pun ke server luar.
- **Izin minimal untuk pengingat lokal:** Jika kamu menyalakan pengingat setoran bulanan, pengingat arus kas harian, atau notifikasi milestone di Pengaturan, Planora hanya meminta izin notifikasi (`POST_NOTIFICATIONS`) dan menggunakan penjadwalan ulang setelah perangkat menyala (`RECEIVE_BOOT_COMPLETED`). Pengingat dibuat lokal di HP tanpa server.
- **Mode Privasi tampilan:** Kamu dapat menyembunyikan seluruh nominal rupiah di layar, grafik, maupun isi notifikasi kapan saja lewat tombol mata di Beranda atau menu Pengaturan.
- **Tidak terhubung ke rekening atau aplikasi lain:** Nama tempat simpanan yang kamu tulis di aplikasi hanyalah catatan pribadi. Planora tidak pernah meminta password, PIN, atau akses akun keuangan mana pun.
- **Kendali penuh di tangan kamu:** Kamu bebas mengekspor data ke file JSON untuk cadangan pribadi, memulihkannya lagi, atau menghapus semuanya lewat menu Hapus Semua Data di Pengaturan.
